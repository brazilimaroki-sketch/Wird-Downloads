# Contributing

Original code contributions are accepted under the Unlicense, unless an explicit existing upstream license applies. Only submit code and assets you have the right to contribute. Preserve upstream license headers and provenance. Do not submit app signing keys, credentials, service-role API keys or local device data.

Keep fixes small, describe expected behavior and run the relevant checks documented in `tests/README_AR.md`. Prayer calculation changes should include comparison dates, exact coordinates, timezone, source and rounding; matching a single prayer on one day is insufficient to establish country-wide accuracy.
