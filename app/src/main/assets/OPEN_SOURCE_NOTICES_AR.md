The repository aggregates tafsir data from Quran.com and QUL/Tarteel sources.
The app loads the selected ayah commentary on demand and keeps a limited local cache.

Offline bundle in this build includes the complete surah JSON files for:
- Tafsir Muyassar
- Arabic Al-Mukhtasar
- Tafsir Ibn Kathir
- Tafsir al-Tabari
- Tafsir al-Qurtubi

Other listed tafsirs can be downloaded by the user and are stored in IndexedDB.
